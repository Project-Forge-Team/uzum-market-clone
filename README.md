# Uzum Market Clone

Клон маркетплейса Uzum — учебный/портфолио-проект, воссоздающий ключевую механику e-commerce платформы: каталог товаров, карточки, навигация и оформление заказа.

## Стек

- **Next.js** + **React** — SSR/SSG, роутинг, API routes
- **TypeScript** — типизация на всём проекте
- **Tailwind CSS** — вёрстка и адаптивность
- **Supabase** — база данных (Postgres), аутентификация, хранилище файлов
- **Git/GitHub** — версионирование

## Возможности

- Каталог товаров с карточками (цена, изображения, рейтинг, скидки)
- Навигация и футер на всех страницах
- Аутентификация пользователей через Supabase Auth
- Админ-панель для управления товарами
- Адаптивная вёрстка под мобильные устройства

## Деплой

Фронтенд — Vercel, бэкенд/БД — Supabase.
